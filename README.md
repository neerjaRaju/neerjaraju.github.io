# Neerja Raju - Developer Portfolio

Personal developer portfolio and GitHub showcase for Android, Flutter, C++, AI and computer vision work.

## Features

- Responsive static HTML, CSS and JavaScript
- Dark/light theme with system preference support
- GitHub profile statistics and repository search
- Data-driven featured projects and project modal
- Privacy-focused mobile developer presentation
- SEO metadata, JSON-LD, favicon, Open Graph image and sitemap
- GitHub Pages compatible with no build step

## Deployment

1. Create or use the repository `neerjaRaju.github.io`.
2. Upload the files to the `main` branch.
3. In GitHub, open Settings, Pages, then choose Deploy from branch, `main`, and `/root`.
4. Visit <https://neerjaraju.github.io/>.

## Customization

Edit `CONFIG` in `script.js` for profile links and contact details. Add featured projects in `data/projects.js`. Project screenshots can be placed in `assets/projects/` and referenced from that data file.
